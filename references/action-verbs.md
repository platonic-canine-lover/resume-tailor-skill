## Usage Guidelines

### Choosing the Right Verb

1. **Match job description language**: If the job posting uses "spearheaded," use that instead of "led"
2. **Be specific**: "Architected" is more precise than "created" for technical roles
3. **Vary verbs**: Don't repeat the same verb multiple times in your resume
4. **Match seniority**: Junior roles use "assisted," senior roles use "directed"
5. **Quantify when possible**: Pair strong verbs with metrics (e.g., "Increased revenue by 40%")

### Common Mistakes to Avoid

- **Passive voice**: "Was responsible for" → "Managed"
- **Vague verbs**: "Worked on" → "Developed," "Led," "Executed"
- **Overused verbs**: "Helped" → More specific action verb
- **Inconsistent tense**: Past roles use past tense, current role uses present tense
- **Redundancy**: "Helped assist" → "Assisted"

### Verb Strength Hierarchy

**Weak** → **Strong**
- Worked on → Executed, Delivered, Completed
- Helped with → Contributed to, Supported, Facilitated
- Was responsible for → Managed, Led, Directed, Owned
- Did → Executed, Performed, Completed, Achieved
- Made → Created, Developed, Established, Built
