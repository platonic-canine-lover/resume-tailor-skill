## Usage Guidelines

### Keyword Integration Best Practices

1. **Exact Match First**: Use exact phrasing from job description
2. **Natural Integration**: Keywords should flow naturally in sentences
3. **Strategic Placement**: Include in Professional Summary, Skills, and Experience sections
4. **Avoid Stuffing**: 2-3 mentions maximum per keyword
5. **Use Variations**: Include acronyms and spelled-out versions (e.g., "SEO" and "Search Engine Optimization")

### ATS Scanning Tips

- **Headers Matter**: Use standard section headers (Work Experience, not "My Journey")
- **Skills Section**: List hard skills with exact tool/software names
- **Consistency**: Match capitalization and formatting from job posting
- **No Graphics**: Text-based keywords only, avoid keyword clouds or graphics
- **Full Company Names**: Include well-known companies in full (not just abbreviations)

### Prioritization Strategy

1. **Must-Have Keywords** (from "Required" section): Include all
2. **High-Value Keywords** (mentioned 3+ times in posting): Prioritize
3. **Nice-to-Have Keywords** (from "Preferred" section): Include if applicable
4. **Industry Standard Keywords**: Include relevant general terms
5. **Emerging Keywords**: New tools/trends mentioned in posting
